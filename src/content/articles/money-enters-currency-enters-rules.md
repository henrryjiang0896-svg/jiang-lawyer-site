> 摘要：跨境资金竞争经常被表述为美元、人民币和稳定币之间的工具竞争。对企业而言，更重要的问题是每一种货币背后连接了哪些银行、清算网络、合规信息和法律救济。本文提出“跨境资金八层审查模型”，用于识别一笔钱进入另一种货币体系后，企业实际上接受了哪些规则。

一家中国企业与境外客户签订合同，可以约定以美元、人民币或者其他货币计价。表面上，这只是价格和付款方式的选择。

但资金真正移动时，问题迅速变得复杂：付款经过哪些银行，谁识别付款人与收款人，哪家机构筛查制裁名单，贸易背景和资金用途如何证明，交易信息能否跨境传输，账户被限制后向谁解释，发生错误支付时依据哪一套法律追索。

因此，企业进入一种货币，不只是接受一个货币符号，也是在进入围绕这种货币形成的支付、账户和合规基础设施。

**本文的判断是：货币国际化的深层竞争，不只是让更多交易使用本国货币，而是把国家实力转化为一套跨法域可执行、可验证、可预期的制度基础设施。强大使别人无法忽视规则，网络使别人难以绕开规则，制度信用则决定别人是否愿意长期采用规则。**

## 一、货币规则如何进入一笔企业付款

假设一家深圳企业向东南亚供应商支付设备款。即使合同真实、货物已经交付，付款仍可能经过开户行、代理行、清算系统、收款行及当地外汇或支付机构。

每个节点都可能提出自己的要求：

- 核验合同主体、实际控制人和受益所有人；
- 判断货物、服务、发票和付款金额是否一致；
- 检查资金来源、资金用途和异常交易模式；
- 筛查交易主体、银行、船舶、国家和地区的制裁风险；
- 保存、传输或依法提供付款人与收款人信息；
- 在信息不足时拒绝、延迟或者限制交易。

FATF修订后的支付透明度标准，进一步强调跨境支付信息的一致性，要求更清楚地识别谁在汇款、谁在收款，并划分汇出、途中和收款金融机构的责任。[FATF Recommendations](https://www.fatf-gafi.org/en/publications/Fatfrecommendations/Fatf-recommendations.html)

这说明，现代跨境支付传输的从来不只有金额。它同时传输身份、交易目的、账户关系和风险判断。

## 二、美元体系的影响力不只来自美元

美元能够向境外交易传导规则，首先来自美国经济、金融市场、技术和地缘政治实力；其次来自美元代理行、清算网络、银行合同和制裁合规形成的全球节点。

大量境外企业并非因为主动认同美国规则而接受审查，而是无法承受失去美元清算、美国市场、美国技术或主要金融机构服务的成本。2026年美国贸易政策议程仍将关税、国家安全和所谓对等贸易放在同一政策框架中，并强调持续监督和执行对华经贸安排。[美国2026年贸易政策议程](https://ustr.gov/sites/default/files/files/Press/Releases/2026/2026%20Trade%20Policy%20Agenda.pdf)

但“无法绕开”并不等于所有参与者都认同这套规则。强制力可以扩大规则覆盖范围，也会提高市场寻找替代支付网络、储备资产和结算通道的动力。这是货币权力中的一个长期悖论。

## 三、人民币国际化不能只看支付量

人民币跨境使用增加，当然需要账户、清算和支付通道。人民银行《人民币国际化报告（2025）》列出了非居民账户、代理行和境外清算行等连接方式，也介绍了CIPS、跨境二维码支付和多边央行数字货币桥等基础设施。[《人民币国际化报告（2025）》](https://www.pbc.gov.cn/huobizhengceersi/214481/3871621/5885243/2025103108544623039.pdf)

但支付通道国际化、贸易结算国际化和储备货币国际化不是同一个层次。

一家企业愿意用人民币支付货款，可能只是为了降低汇兑成本；愿意保留人民币余额，需要流动性和风险管理工具；愿意长期持有人民币债券或把储备留在人民币体系，还涉及资产安全、政策可预测性、市场深度和争议救济。

因此，人民币国际化的关键不仅是“钱能不能过去”，还包括：

- 境外主体能否理解并信任人民币账户和清算规则；
- 合规信息能否在不同法域之间验证，而不被无边界使用；
- 交易被拒绝、冻结或错误处理时，是否存在可预期的解释和救济；
- 人民币资产能否方便地取得、交易、对冲和退出；
- 不同国家的法律、银行和支付系统能否共同执行一套规则。

## 四、数字人民币输出的可能是一套“合规协议”
多边央行数字货币桥的重要性，不只在于减少代理行层级、提高结算速度。BIS对mBridge的介绍显示，该项目不仅建设技术平台，还形成与平台治理相匹配的规则手册、法律框架和合规机制，用来协调不同司法辖区的法律和国际标准。[BIS Project mBridge](https://www.bis.org/project/mbridge)

长期看，不同跨境支付系统之间的竞争，可能越来越取决于它们能否携带并验证标准化信息：

- 谁付款、谁收款；
- 实际控制人和受益所有人是谁；
- 交易对应什么合同、货物或服务；
- 发票、物流、报关和付款是否一致；
- 是否完成反洗钱与制裁筛查；
- 数据可以向谁提供、保存多久、如何调取；
- 出现错误或争议时由谁负责。

能够让这些信息跨法域验证，同时限制不必要披露的支付网络，才可能形成真正的企业端优势。

这也意味着，数字人民币跨境发展不应只宣传“更快到账”。它还需要回答一系列制度问题：参加机构依据什么准入，系统记录如何成为证据，交易限制如何解释，不同法域发生冲突时适用什么规则，以及企业如何退出。

## 五、实力决定进入，信用决定留下

近期中美经贸互动再次说明，大国规则并不是脱离实力的中立文本。双方通过关税、市场、产业链和关键资源形成谈判能力，又通过政府间磋商和联合安排把力量关系转化为相对稳定的制度预期。中方在2026年9月中美元首会谈中，将平等、尊重、互惠以及压缩问题清单作为稳定经贸关系的重要条件。[中美元首会谈](https://www.mfa.gov.cn/ziliao_674904/zt_674979/dnzt_674981/xjpdmgjxgsfw/zxxx_159164/202609/t20260925_12031134.shtml)

但企业不会仅凭国家力量长期持有一种货币。真正稳定的货币网络需要三层基础：

1. **实力产生不可忽视性**：市场、产业、技术或资源让境外主体必须考虑这套规则；
2. **网络产生默认性**：银行、企业和平台已经广泛接入，退出和另建体系成本很高；
3. **制度信用产生自愿持有**：参与者相信资产安全、规则稳定、信息使用受约束，争议可以获得救济。

所以，可以把货币国际化压缩成一句话：

> 货币国际化既以综合实力为支撑，也以制度信用为基础：前者让市场愿意使用，后者让资金愿意长期留下。

## 六、企业应当审查的八层问题

宏观货币竞争最终会落到企业的一笔笔交易上。企业选择美元、人民币、稳定币、数字人民币或代币化存款时，可以使用八层审查模型：

| 层次 | 核心问题 |
| --- | --- |
| 交易 | 资金为什么支付，基础合同和履约是否真实 |
| 主体 | 谁签约、付款、收款和控制，受益所有人是谁 |
| 货币 | 用什么计价、支付和持有，汇率及资产风险由谁承担 |
| 通道 | 经过哪些银行、钱包、清算系统或链上节点 |
| 控制 | 谁能拒绝、冻结、退回、分账或改变资金用途 |
| 合规 | KYC、反洗钱、制裁与交易监测义务如何分配 |
| 税务与数据 | 资金被认定为什么性质，哪些信息随交易跨境流动 |
| 证据与救济 | 发生限制、误付或违约时如何证明、申诉和追索 |

这八层不会因为支付技术更先进而消失。新的支付工具可能缩短资金路径，却也可能增加钱包运营者、智能合约、数据提供者和技术平台等新的控制节点。

企业真正要比较的，不只是手续费和到账速度，而是选择一种货币和通道后，自己进入了谁的规则、需要提交什么信息、可能在哪个节点失去资金控制，以及发生问题后能否获得有效救济。

## 结语

货币是价值尺度和支付工具，也是法律、金融、数据与国家力量的共同载体。

对律师而言，研究数字人民币、跨境资金、制裁、反洗钱、税务和数据合规，不是同时涉足几个不相干的热门领域，而是在回答同一个问题：

> 一笔钱跨越账户、国境和货币体系时，如何被识别、控制、征税、冻结、证明和救济？

这也应当成为企业选择跨境资金路径时的起点。
